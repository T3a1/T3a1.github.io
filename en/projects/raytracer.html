NAME

raytracer — ray tracing renderer

SYNOPSIS

./raytracer scene.cfg [-a samples]

./raytracer --hardcoded

DESCRIPTION

Reads a scene from a configuration file, casts one or more rays per pixel and writes the image as a PPM file. A quick preview comes first, then the full render; when the scene file changes, the image is rendered again. A second-year project.

DESIGN

  • Interfaces and plugins. Shapes and lights implement IShape and ILight, are built by factories, and also ship as shared libraries loaded with dlopen.
  • Builder. One scene builder reads .cfg files (libconfig++), another provides a hard-coded test scene.
  • Shapes. Sphere, plane, cylinder, cone, limited versions, triangle, OBJ meshes and groups.
  • Rendering. Shadows, transparent objects that let part of the light through, textures, anti-aliasing, and a BVH to speed up intersections on large meshes.

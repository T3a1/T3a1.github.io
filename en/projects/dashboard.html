NAME

dashboard — personal dashboard of web widgets

SYNOPSIS

docker compose up [--build]

DESCRIPTION

Each user picks services (weather, cryptocurrency, NASA, Duolingo, GitHub) and places their widgets on a grid. Every widget has its own settings and refresh rate, from 10 seconds to a day. A third-year pair project.

browser ──► nginx ──┬── React app (static files)
                    └── /api ──► .NET 10 API ──┬── PostgreSQL
                                     │         └── Mailpit (emails)
                                     └── background refresh
                                         ──► Open-Meteo, CoinGecko, NASA,
                                             Duolingo, GitHub

ROLE

I wrote the .NET API and its test suite, sign-in with Google and Microsoft (OpenID Connect), GitHub account linking over OAuth, the containers and the documentation. My teammate built the React interface.

DESIGN

  • Server-side refresh. The server updates every widget in the background and keeps the latest result; the page only reads it. A hundred open tabs do not mean a hundred calls to the weather provider.
  • No third-party password. GitHub is linked in one click on its own consent page; no password or key is ever typed into the application.
  • Accounts. Sign-up confirmed by email, token-based login, an administrator role to manage accounts.
  • Tests. 193 xUnit integration tests, with fake providers (weather, GitHub, OIDC…) so no external service is needed.
  • Running it. One docker compose up: database, test mailbox, API and interface.
  • Documented decisions. Sixteen design decisions, each with the options considered, what it buys and what it costs.

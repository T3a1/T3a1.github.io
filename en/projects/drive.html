NAME

drive — self-hosted family storage

SYNOPSIS

wg-quick up drive

DESCRIPTION

A personal project. My family wanted to stop depending on an external cloud and to have as much space as needed. I set up a NAS on a Raspberry Pi that everyone uses, at home or away.

at home:   family devices ──────────────────────────┐
                                                    ▼
away:      device ══ WireGuard tunnel ══► Raspberry Pi
                                          OpenMediaVault
                                                    │
                                                    ▼
                                          automatic backups

DESIGN

  • Remote access without exposure. The server is not open to the Internet: from outside, it is reached through a WireGuard VPN.
  • Accounts and rights. One account per family member, each with its own access rights, managed in OpenMediaVault.
  • No data loss. Data is backed up automatically.

This project is what got me into administration: running a service other people rely on.

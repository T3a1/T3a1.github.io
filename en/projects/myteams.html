NAME

myteams — command-line team chat

SYNOPSIS

myteams_server port

myteams_cli ip port

DESCRIPTION

A server and a command-line client, in the spirit of Microsoft Teams. Users log in, create teams, channels inside teams, threads inside channels and replies inside threads, and send each other private messages. A second-year project.

team
 └── channel
      └── thread
           └── reply          + private messages between users

DESIGN

  • One poll() loop. The server serves every client without threads.
  • Custom protocol. Text commands and status codes, described in an RFC-style specification.
  • Live notifications. Users subscribed to a team are told as soon as a channel, thread or reply appears in it.
  • Persistence. Every entity has a UUID; everything is saved to disk and loaded back at startup.
  • Context. /use sets the current team, channel or thread, and /create, /list, /info act on it.
